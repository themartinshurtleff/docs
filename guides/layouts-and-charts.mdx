# Workspaces and Layouts

A TradeNet workspace is the entire working surface, not only one chart.

It includes your panes, pane settings, split tree, canvas positions, layout mode, selected pane, link state, and tab groups.

## Docked split mode

Docked split mode keeps panes in a structured layout.

Use it when you want:

- Predictable rows and columns
- Shared borders with draggable dividers
- A clean layout that fills the available window
- Fast tab splitting into the top, bottom, left, or right side of another pane

Drag a divider to resize the panes on either side.

## Freeform canvas mode

Freeform canvas mode gives you a larger scrollable surface where panes can overlap.

In canvas mode you can:

- Spawn panes directly
- Drag a pane by its header
- Resize it from its handles
- Click a pane to bring it forward
- Use snapping to keep placements clean
- Scroll across the larger workspace

The canvas is useful for complex layouts or when you want independent pane sizes that do not fit a strict grid.

## Save a workspace

<Steps>
  <Step title="Build the layout">
    Add panes, choose split or canvas mode, configure markets, arrange tabs, and set pane options.
  </Step>
  <Step title="Open WORKSPACES">
    Use the menu in the top bar.
  </Step>
  <Step title="Name and save">
    Enter a clear name such as `BTC Order Flow`, then choose the save button.
  </Step>
  <Step title="Optional: star it">
    A starred workspace loads automatically when TradeNet starts.
  </Step>
</Steps>

Saved workspaces can be loaded or deleted from the same menu.

## What a workspace does not carry

Drawings stay attached to their original pane identity. A saved workspace template can recreate pane structure and settings, but it does not copy drawings into newly created pane IDs.

If you want reusable drawing styles, save a [drawing template](/features/drawing-tools).

## Session restore

TradeNet persists the active workspace so a normal restart can restore what you were using. A named workspace template is still worth saving before a major rearrangement.
