# Templates, Themes, and Settings

TradeNet has several kinds of templates. They solve different problems.

## Workspace templates

Workspace templates save the full terminal arrangement:

- Panes and pane settings
- Docked split tree
- Canvas positions and sizes
- Split or canvas mode
- Selected pane
- Link state
- Tab groups

Open **WORKSPACES** in the top bar to save, load, star, or delete them.

## Chart templates

A chart template saves the chart setup without replacing the market identity. It can include chart style, heatmap choice, indicators, chart display settings, and related pane configuration.

Star a chart template to use it as the starting point for new charts.

## Indicator templates

Indicator templates save settings for one indicator, including supported venue choices, display options, and colors.

The terminal also remembers recent direct settings, so a newly added copy starts closer to the way you last used it.

## Drawing templates

Drawing templates save tool-specific appearance and behavior. Volume-profile templates can include source, rows, venues, placement, profile mode, POC, value area, node settings, and secondary-profile settings.

Geometry, object IDs, lock state, and cached runtime data are not copied.

## Theme editor

Open the palette icon in the left rail to customize the chart theme. Use readable contrast between the chart background, text, grid, buy colors, sell colors, and heatmap palettes.

## Settings

The Settings panel includes:

- UTC or local timezone
- Global aggregation venue preferences
- Account and sign-out controls
- Advanced-order defaults
- Diagnostics and logs
- App version
- Manual update check

Global aggregation settings can apply a venue set across panes and lock panes to that choice. This affects aggregated klines, footprints, bar stats, backend metrics, row indicators, and venue-aware overlays.

<Tip>
Save one clean workspace before experimenting. It gives you a known layout to return to if a complex canvas or tab arrangement stops being useful.
</Tip>
