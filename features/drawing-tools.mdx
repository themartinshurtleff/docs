## Select and edit

Switch back to the cursor, then click a drawing. TradeNet uses forgiving screen-space hit areas so thin lines and profile borders do not require a pixel-perfect click.

Selected unlocked drawings can be moved, resized, deleted, or opened in settings.

## Lock drawings

Use the lock action in the selected drawing toolbar when you do not want an object moved by accident.

A locked drawing:

- Can still be selected
- Shows an unlock-only quickbar
- Cannot be moved or resized
- Cannot have its settings or template changed
- Cannot be deleted normally
- Does not show resize handles

Unlock it before editing.

## Tool lock

The lock button at the bottom of the drawing toolbar controls tool repetition. When tool lock is on, the selected drawing tool stays active after you place an object.

This is separate from locking an individual drawing.

## Undo, redo, and persistence

Drawings use chart data coordinates, so they remain attached to time and price while you pan or zoom. Drawing state, including object lock state, is persisted for the pane.

Use undo and redo for recent drawing changes.

## Drawing templates

When a non-cursor tool is selected, open its template menu to:

- Save the current tool settings
- Apply a saved template
- Star a default template
- Delete a template

Direct changes also become the recent defaults for that tool.

Volume profiles have more settings than a line or shape. Their templates preserve profile source, rows or tick binning, venue selection, placement, profile mode, POC and value-area behavior, node settings, and supported secondary-profile options.

## Timeframe visibility

Drawing settings can limit an object to appropriate timeframe ranges. Use this when a short-term execution level should not clutter a higher-timeframe chart.

For volume-profile details, read [Volume Profiles and TPO](/features/volume-profiles-and-tpo).
