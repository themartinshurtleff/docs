# Drawing Tools & Volume Profile

Mark up your charts and profile the volume behind them. Every tool persists with your layout, so your work is still there when you come back.

## Line tools

The standard kit, built for speed:

- Trend line
- Horizontal line and horizontal ray
- Vertical line
- Extended line
- Parallel channel
- Rectangle
- Text labels
- Freehand pencil

Draw it, select it, adjust it. No menus in your way.

## Fibonacci retracement

Two-anchor Fibonacci with full per-level control:

- Configure each level individually: color, visibility, position.
- Fill bands between levels for instant visual zones.
- Reverse and extend toggles for working both directions and projecting beyond the anchors.

## Fixed Range Volume Profile

Select a start and end on the chart and get the volume-at-price histogram for that range.

- **POC line.** The price level with the most traded volume in the range.
- **Value area.** Configurable percentage, default 70. VAH and VAL guide lines mark its edges.
- **Up to 500 rows.** Enough resolution to profile a week or zoom into a single session.
- **Buy/sell split coloring.** See which side of the volume dominated at each level.
- **Imbalance highlighting.** Levels where one side heavily outweighed the other get flagged.
- **High volume node markers.** Significant volume concentrations marked automatically.

<Note>
When footprint data is available for the range, the profile is built from real per-level trade data. Exact, not estimated. When it is not, the profile falls back to candle approximation and tells you so on the profile itself.
</Note>

## Anchored Volume Profile

Same engine, one anchor. Place the anchor and the profile develops live from that point to the current bar, updating as new prints come in.

Use it for session profiles, swing profiles, or profiling from any event you care about. Anchor at the session open, a CPI print, or a swing low, and watch value build in real time. All FRVP settings apply: POC, value area, splits, imbalances, node markers.

## TPO Profile

A TPO (time-price-opportunity) indicator that shows how much time price spent at each level, rendered as letters or cells.

- Session-based, default daily UTC sessions.
- POC, VAH, and VAL per session.
- Single-print highlighting for levels price touched only briefly.
- Multiple gradient color presets.

Volume profiles tell you where size traded. TPO tells you where time was spent. The two together separate acceptance from rejection.

## Object management

- Select any drawing to open its settings.
- Lock drawings you do not want to nudge by accident. Unlock to edit again.
- Delete individual objects or clear them out.
- Save tool templates for setups you reuse.
- New objects inherit your last-used settings, so you are not reconfiguring the same trend line every time.

Everything persists with your layout. Close the terminal, come back tomorrow, your levels are exactly where you left them.
