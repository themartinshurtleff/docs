Every indicator's `compute` and `draw` functions receive a single `ctx` object. This page documents every member.

<Note>
All indices are 0-based. Index 0 is the oldest candle, `ctx.candle_count() - 1` is the live candle. Out-of-range reads return `nil`. `ipairs` and `#` do not work on `ctx` tables, use explicit loops.
</Note>

## Metadata

| Member | Returns | Notes |
|--------|---------|-------|
| `ctx.candle_count()` | integer | Number of candles loaded in the pane |
| `ctx.timeframe()` | number | Timeframe in milliseconds |
| `ctx.symbol()` | string | e.g. `"BTCUSDT"` |
| `ctx.exchange()` | string | See values below |
| `ctx.tick_size()` | number | Price tick size of the symbol |

`ctx.exchange()` returns one of: `"BinanceLinear"`, `"BinanceInverse"`, `"BinanceSpot"`, `"BybitLinear"`, `"BybitInverse"`, `"BybitSpot"`, `"HyperliquidLinear"`, `"HyperliquidSpot"`, `"OkexLinear"`, `"OkexInverse"`, `"OkexSpot"`, `"Aggregated"`.

## Candle data

Per index `i`. All return number or `nil`.

| Member | Returns |
|--------|---------|
| `ctx.open(i)` | Open price |
| `ctx.high(i)` | High price |
| `ctx.low(i)` | Low price |
| `ctx.close(i)` | Close price |
| `ctx.volume(i)` | Total volume |
| `ctx.buy_volume(i)` | Buy volume |
| `ctx.sell_volume(i)` | Sell volume |
| `ctx.time(i)` | Candle open timestamp in ms |

## Bar stats

Per index `i`. All return number or `nil`.

| Member | Returns |
|--------|---------|
| `ctx.delta(i)` | Buy minus sell volume |
| `ctx.daily_cvd(i)` | Daily session CVD, resets at UTC midnight (preferred) |
| `ctx.cvd_24h(i)` | Alias of `daily_cvd`. NOT a rolling 24h window |
| `ctx.oi_delta(i)` | OI change over the candle, in USD |
| `ctx.daily_oi_cvd(i)` | Daily OI CVD, in USD |
| `ctx.oi_cvd(i)` | Alias of `daily_oi_cvd` |
| `ctx.liq_short(i)` | Short liquidations, USD |
| `ctx.liq_long(i)` | Long liquidations, USD |

<Warning>
Bar stats can be `nil` per candle, even mid-series. Always guard before using the value.
</Warning>

## Status and sessions

| Member | Returns | Notes |
|--------|---------|-------|
| `ctx.is_live(i)` | bool | True only for the open candle |
| `ctx.is_confirmed(i)` | bool | True for closed candles |
| `ctx.session_id(i, reset_hour_utc)` | integer | Session bucket the candle belongs to |
| `ctx.is_session_reset(i, reset_hour_utc)` | bool | True on the first candle of a session |
| `ctx.is_utc_day_reset(i)` | bool | True on the first candle of a UTC day |

## Footprint

`ctx.footprint(i)` returns a 0-indexed table of levels, or `nil`. Each level is a table:

```lua
{ price, buy_qty, sell_qty, buy_count, sell_count }
```

Quantities are base asset on all pane types. Levels are NOT sorted by price.

<Warning>
`#` and `ipairs` do not work on the footprint table. Iterate with a `while` loop until `nil`:

```lua
local fp = ctx.footprint(i)
if fp then
    local j = 0
    while fp[j] do
        local level = fp[j]
        -- level.price, level.buy_qty, level.sell_qty, level.buy_count, level.sell_count
        j = j + 1
    end
end
```
</Warning>

## Liquidation impact levels

Live-only tap into the model-scored significant levels shown as impact bands on the liquidation heatmap. See [Impact levels](/docs/features/liquidation-heatmap#impact-levels) for what the score means.

| Member | Returns |
|--------|---------|
| `ctx.liq_impact_levels()` | Table or `nil` |

Returns a 0-indexed table of levels plus two extra fields, or `nil` when the pane has no liquidation layer:

- Each level: `{ price, side, usd, peak_usd, impact, dual_source, isolation, size_percentile, distance_pct, age_min }`. `side` is `"long"` or `"short"`. `impact` is a model probability from 0 to 1.
- `count`: number of levels in the table.
- `touch_rate`: live measured accuracy from the level ledger (0 to 1), or `nil` while warming up.

Up to 12 levels per side, sorted by impact descending.

<Warning>
Honesty rules carry into Lua. The table is empty when the live snapshot is stale (older than 30 seconds), during backend warm-up after a restart, or on panes without backend liquidation data (per-exchange panes typically have none, aggregated BTC/ETH/SOL are the home of this data). `usd` is a model estimate, label it as modeled, never as exact resting size. Do not rank-compare scores above roughly 0.7, calibration flattens for ultra-close levels.
</Warning>

## Bulk series

Each call returns a fresh Lua table. Call once and reuse, do not call inside loops.

| Member | Returns |
|--------|---------|
| `ctx.closes()` | Table of close prices |
| `ctx.highs()` | Table of high prices |
| `ctx.lows()` | Table of low prices |
| `ctx.opens()` | Table of open prices |
| `ctx.volumes()` | Table of volumes |
| `ctx.deltas()` | Table of deltas |

<Warning>
On Aggregated panes, candles with missing bar stats appear as NaN in these tables. Guard with `v == v` (NaN is not equal to itself). Prefer the indexed accessors (`ctx.close(i)` etc.) in loops, they return `nil` instead.
</Warning>

## Math helpers

Computed natively, fast. Signature: `ctx.helper(field, period, i)`. Return number or `nil` when the window is not full.

| Member | Notes |
|--------|-------|
| `ctx.sma(field, period, i)` | Simple moving average |
| `ctx.ema(field, period, i)` | Seeded with SMA of the first `period` values. O(i) cost per call, cache results |
| `ctx.rsi(field, period, i)` | Wilder smoothing, returns 0-100 |
| `ctx.stdev(field, period, i)` | Population standard deviation |
| `ctx.highest(field, period, i)` | Tolerates partial windows |
| `ctx.lowest(field, period, i)` | Tolerates partial windows |

Valid field names, exactly: `"close"`, `"open"`, `"high"`, `"low"`, `"volume"`, `"buy_volume"`, `"sell_volume"`, `"delta"`. Any other field raises an error.

<Tip>
`ctx.ema` recomputes from the start of the series each call. Calling it for every index in a loop is fine. Calling it inside nested loops is not. Cache the values in a local table.
</Tip>

## Compute output

| Member | Notes |
|--------|-------|
| `ctx.set_value(i, v)` | Sets the primary series. Drives the panel Y-scale and the auto-rendered line |
| `ctx.set_series(i, v, name)` | Sets a named series. Feeds `draw_band` and the hover readout. Name comes LAST |
| `ctx.break_before(i)` | Starts a new line segment at `i`. Use for session resets. Must be re-marked every compute |

## Draw commands

Call these in `draw()`. Max 10,000 commands per draw call. Widths, sizes, and radii are screen pixels. Colors are `"#rrggbb"` or `"#rrggbbaa"` hex strings.

| Command | Modes | Notes |
|---------|-------|-------|
| `ctx.draw_line(from_i, from_y, to_i, to_y, color, width)` | both | |
| `ctx.draw_hline(y, color, width, style)` | both | `style` is `"solid"`, `"dashed"`, or `"dotted"` |
| `ctx.draw_label(i, y, text, color, font_size)` | overlay only | |
| `ctx.draw_rect(from_i, from_y, to_i, to_y, fill_color, border_color)` | overlay only | `border_color` optional |
| `ctx.draw_circle(i, y, radius, color)` | overlay only | |
| `ctx.draw_bar(i, value, color)` | panel only | Any `draw_bar` replaces the auto primary line |
| `ctx.draw_band(upper_name, lower_name, fill_color)` | both | Errors if the named series were not populated in compute |

## State and settings

`ctx.state` is a persistent Lua table. It survives between `compute` and `draw` and across runs. One VM per pane per script. You get a fresh VM when the indicator is toggled off and on, the pane type changes, or the app restarts.

`ctx.settings` is read-only and holds your declared setting values.

## Units

This section matters. Get it wrong and your numbers are off by orders of magnitude.

| Pane type | Volume / delta / CVD | Footprint quantities | OI / liquidations |
|-----------|----------------------|----------------------|-------------------|
| Aggregated | USD notional, served from backend bar stats, `nil` where not loaded | Base asset | USD |
| Exchange panes | Follows the terminal's volume mode (base or quote) | Base asset | USD |

Detect aggregated panes with:

```lua
if ctx.exchange() == "Aggregated" then
    -- volume, delta, CVD are USD notional here
end
```

<Note>
There is no `volume_unit()` helper. The exchange check above is the only way to branch on units.
</Note>

## Sandbox

Scripts run in Lua 5.4 with a locked-down environment.

| | |
|---|---|
| Removed | `io`, `os`, `debug`, `require`, `package`, `load`, `coroutine` and friends |
| Available | `math`, `string` (no `dump`), `table` |
| Network | None. No REST endpoints. Indicators read only the data already loaded in the pane |
| Filesystem | None |
| Memory | 32 MB |
| Time | 100ms per compute, 50ms per draw |

<Note>
`print()` is rate-limited and not surfaced in the UI. Debug visually instead: draw labels in overlay mode, or push values into a named series and read them in the hover readout.
</Note>

## Patterns

### Session-reset cumulative series

Cumulative values like daily OI CVD reset per session. Use `break_before` so the line breaks instead of drawing a vertical jump. Re-mark the break every compute.

```lua
local reset_hour_utc = 0
local last_session = nil
for i = 0, ctx.candle_count() - 1 do
    local val = ctx.daily_oi_cvd(i)
    if val then
        local session = ctx.session_id(i, reset_hour_utc)
        if last_session and session and session ~= last_session then
            ctx.break_before(i)
        end
        if session then last_session = session end
        ctx.set_value(i, val)
    end
end
```

### Footprint VWAP

Per-candle VWAP from footprint levels. Note the while loop, the nil guard, and that levels are unsorted (order does not matter for a sum).

```lua
for i = 0, ctx.candle_count() - 1 do
    local fp = ctx.footprint(i)
    if fp then
        local pv, qty = 0, 0
        local j = 0
        while fp[j] do
            local lvl = fp[j]
            local q = lvl.buy_qty + lvl.sell_qty
            pv = pv + lvl.price * q
            qty = qty + q
            j = j + 1
        end
        if qty > 0 then
            ctx.set_value(i, pv / qty)
        end
    end
end
```
